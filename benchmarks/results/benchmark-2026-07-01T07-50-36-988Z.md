## Notes

- Fixtures include realistic CSS: hex colors (#fff, #1a73e8), misspellings (flexbox, abs, hand, centered), semantic intents, media queries, and dead rules
- Cold start includes Node.js JIT compilation and module loading
- Memory metrics: Start = before benchmark, Peak = highest during run, End = after all iterations
- Pass timings from pipeline's built-in timeline
- Dead rules: input fixtures have ~2% dead rules; dead-code-eliminator removes them
- CSS savings from css-compressor (hex shortening, whitespace removal)
